# 🖼️ Image Classification Web App

A lightweight web application built with **Streamlit**, **Hugging Face Transformers**, and **PyTorch** that classifies uploaded images using Google's **Vision Transformer (ViT)** model.

---

## ✨ Features
* 🚀 Powered by Google's `google/vit-base-patch16-224` Vision Transformer model.
* 📤 Simple and clean drag-and-drop UI built with Streamlit.
* 📊 Displays class labels alongside confidence scores and progress bars.
* ⚡ Cached model loading for fast predictions after initial startup.
